# وقاية (Wiqaya) — الفحص الانتهازي الوقائي من الأشعة

نظام دعم قرار لأخصائي الأشعة: يستخرج من أي أشعة مقطعية أُجريت لسبب آخر مؤشرات كمية
ترتبط بأمراض مزمنة قبل ظهور أعراضها (هشاشة العظام، التشحّم الكبدي، أم الدم الأبهرية،
تصلّب الشرايين، النفاخ الرئوي، الساركوبينيا)، ويربط كل نتيجة بمرجعها العلمي وبتوصية وقائية.

> **تنبيه مهم.** هذا برنامج بحثي/تجريبي وليس جهازًا طبيًا مرخّصًا. لا يجوز استخدامه في قرار
> سريري قبل: (1) تحقق محلي على بيانات المستشفى، (2) موافقة الجهة التنظيمية (مثل SFDA)
> ولجنة الأخلاقيات، (3) اعتماد أخصائي أشعة لكل تقرير. النظام **لا** يكشف الأورام أو
> العقيدات الرئوية أو الكسور أو أي حالة حادة.

## التشغيل

```bash
python -m venv .venv && . .venv/bin/activate
pip install torch --index-url https://download.pytorch.org/whl/cpu   # أو نسخة CUDA إن وُجد GPU
pip install -e ".[models,dev]"

python -m wiqaya selftest                 # تحقق من صحة كل قياس على مجسّم رقمي معلوم القيم
python -m wiqaya serve --host 0.0.0.0     # الواجهة: http://<server>:8000
python -m wiqaya analyze study.zip --sex M --height-cm 172 --out out/   # سطر الأوامر
pytest                                     # 63 اختبارًا
```

أول تحليل يُنزّل أوزان نموذج التقطيع (مرة واحدة)؛ بعدها يعمل النظام دون إنترنت.

| متغير البيئة | الوظيفة |
|---|---|
| `WIQAYA_TOKEN` | رمز دخول مشترك للواجهة والـ API (يُنصح به دائمًا) |
| `WIQAYA_DATA` | مجلد قاعدة البيانات وسجل التدقيق (الافتراضي `runs/`) |
| `WIQAYA_DEVICE` = `cpu`/`gpu`، `WIQAYA_FAST` = `0`/`1` | الجهاز ودقة التقطيع (CPU: نموذج 3 مم ≈ دقيقة؛ GPU: نموذج 1.5 مم) |
| `WIQAYA_KEEP_UPLOADS=1` | الاحتفاظ بالملفات المرفوعة (الافتراضي: تُحذف بعد التحليل) |

يجب وضع الخادم خلف HTTPS (reverse proxy) داخل شبكة المستشفى.

## ما الذي يقيسه

| المجال | القياس | العتبة والمرجع | شرط الصلاحية |
|---|---|---|---|
| العظام | متوسط HU للعظم الإسفنجي في L1 | ≤110 HU نوعية >90% للهشاشة؛ >160 HU تستبعدها بحساسية 90% (Pickhardt 2013) | 120 kVp |
| الكبد | وسيط HU للكبد | ≤40 HU تشحّم متوسط–شديد (Boyce 2010)؛ <48 HU عالي النوعية (Pickhardt 2012) | دون تباين |
| الأبهر | أقصى قطر (دائرة محاطة) | بطني ≥30 مم أم دم (SVS 2018)؛ صدري ≥40 مم توسّع (ACC/AHA 2022) | تأكيد يدوي |
| الكالسيوم | Agatston للأبهر البطني ومنطقة القلب | 1–99 / 100–399 / ≥400 (SCCT/STR 2016) | دون تباين، ضجيج مقبول |
| الرئتان | نسبة الحجم تحت −950 HU | ≥5% | شهيق كامل، مرشح ناعم |
| تركيب الجسم | عضلات / دهن حشوي / تحت الجلد عند L3 | SMI: 52.4 ذكور، 38.5 إناث (Prado 2008) | يتطلب الطول |
| أشعة الصدر (تجريبي) | النسبة القلبية الصدرية | >0.50 | صورة PA قائمة |

التفاصيل والمراجع الكاملة في [docs/SCIENCE.md](docs/SCIENCE.md).

**أنواع الأشعة.** يقرأ النظام DICOM (مجلد، ZIP، متعدد الإطارات)، NIfTI، والصور العادية.
التحليل الكمي متاح للأشعة المقطعية للجذع ولأشعة الصدر الأمامية. بقية الأنواع (رنين، ماموغرام،
موجات صوتية...) تُقرأ وتُفحص جودتها ويُذكر صراحةً أنه لا توجد لها خوارزمية مُتحقَّق منها — لا يخمّن النظام.

## كيف يقلّل الأخطاء

- **الامتناع بدل التخمين:** كل قياس يُطبَّق فقط ضمن شروطه (تباين، ضجيج، kVp، اكتمال العضو في
  مجال الفحص). ما لا يتحقق شرطه يظهر في جدول «لم يُقيَّم» مع السبب، ولا يُعدّ طبيعيًا.
- **كشف التباين الوريدي آليًا** من توهين الدم، وتعطيل قياسات الكبد والكالسيوم عند وجوده.
- **قياسات حتمية:** لا يوجد مكوّن متعلَّم في الحساب نفسه؛ التعلم العميق يُستخدم فقط لتحديد التشريح.
- **صورة مفتاحية لكل قياس** تُظهر موضعه بالضبط ليتحقق منه الأخصائي بنظرة.
- **اعتماد إلزامي:** التقرير «مسودة» حتى يحدد الأخصائي قراره لكل نتيجة؛ بعد الاعتماد لا يُعدَّل، وكل إجراء في سجل تدقيق.
- **الخصوصية:** لا يُخزَّن اسم المريض أو رقمه (معرّف مستعار فقط)، تُحذف الملفات الخام بعد التحليل،
  لا يخرج أي شيء من الخادم، وإحصاءات الاستخدام في مكتبة التقطيع معطّلة قسرًا.

## التحقق المنجز

1. **مجسّم رقمي** معلوم القيم: كل قياس يطابق الحقيقة ضمن هامش محدد (`python -m wiqaya selftest`).
2. **63 اختبارًا آليًا**: القياسات، حدود العتبات، قراءة DICOM (ترتيب عشوائي، مقاطع مفقودة، اتجاهات)، الخادم.
3. **دراسة توافق على أشعة حقيقية عامة**: القياس بالتقطيع الآلي مقابل التقطيع المرجعي — [docs/validation/SUMMARY.md](docs/validation/SUMMARY.md).

ما **لم** يُنجز ويلزم قبل الاستخدام السريري: مقارنة مع المعيار المرجعي (DXA، خزعة/MRI-PDFF، كالسيوم
مبوَّب، قياس يدوي للأبهر) على مرضى المستشفى، وعلى أجهزته وبروتوكولاته.

## البنية

```
wiqaya/io.py          قراءة أي صيغة → حجم موحّد الاتجاه (RAS) + تحذيرات
wiqaya/segment.py     التقطيع التشريحي (TotalSegmentator) في عملية معزولة
wiqaya/biomarkers.py  القياسات الكمية الحتمية
wiqaya/rules.py       العتبات والمراجع → نتائج وتوصيات (مصدر واحد للحقيقة)
wiqaya/cxr.py         أشعة الصدر (تجريبي)
wiqaya/pipeline.py    المسار الكامل وضبط الجودة والصور المفتاحية
wiqaya/server.py      خدمة الويب، قائمة الانتظار، الاعتماد، سجل التدقيق
wiqaya/phantom.py     المجسّم الرقمي المرجعي
```

التراخيص: TotalSegmentator (Apache-2.0، أوزان مهمة `total` مفتوحة)، TorchXRayVision (Apache-2.0، أوزان بحثية).
